# 사이트 UI 단순화 및 어린이 친화 UX 구상 체크리스트

**생성일**: 2026-05-04
**대상**: 매쓰 펫토리 전체 주요 화면

## 목표
난잡한 시각 요소를 줄이고, 초등학생이 원하는 학습을 쉽게 찾을 수 있는 심플하고 깔끔한 구조로 개선한다.

## 1단계: 현재 UI 문제 진단
- [ ] 홈 화면 CTA가 너무 많아 첫 행동이 분산되는 문제 확인
- [ ] 학년 선택, 커리큘럼, 추가 도구 카드의 시각 체계가 서로 다른 문제 확인
- [ ] 이모지, 색상, 그림자, 둥근 카드가 과도하게 섞이는 문제 확인
- [ ] Curriculum 페이지에서 단원과 도구가 같은 카드 밀도로 나열되어 우선순위가 흐려지는 문제 확인

## 2단계: 새 정보 구조 설계
- [ ] 홈 화면 핵심 행동을 1개로 축소: “내 학년 선택하기”
- [ ] 학년 화면을 3개 섹션으로 정리: 오늘 배울 단원 / 연습하기 / 출력하기
- [ ] 추가 도구는 학습 도구가 아닌 “빠른 메뉴” 카드로 분리
- [ ] 부모용·SEO 설명은 접이식 또는 하단 조용한 섹션으로 이동

## 3단계: 디자인 시스템 정리
- [ ] 컬러 팔레트를 3개 중심으로 제한: 배경, 주요색, 보조색
- [ ] 카드 스타일 통일: 흰 배경, 얇은 테두리, 약한 그림자
- [ ] 카드 크기와 제목/설명/버튼 위치 통일
- [ ] 이모지는 섹션 제목 또는 주요 액션에만 제한

## 4단계: 어린이 UX 개선
- [ ] 큰 버튼, 짧은 문장, 명확한 다음 행동 제공
- [ ] “탐험하기”, “문제 풀기”, “학습지 뽑기”처럼 행동 중심 문구 사용
- [ ] 학년별 가장 중요한 3~4개 활동을 상단에 추천
- [ ] 모바일에서 한 손으로 누르기 쉬운 카드 크기 확보
